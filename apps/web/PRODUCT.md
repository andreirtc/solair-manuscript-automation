## Product Purpose
Help the team request evidence-based manuscript revisions in natural language, read exact proposed changes, approve deliberately, preserve native Google Docs formatting and review a final frozen PDF.
## Operating Context
Start page → genuine workspace sign-in → main chat. Three primary views: Chat, Review changes, History. Optional tools: sources, school formatting, equations, print review, team/account settings. Conversation is the default manuscript task; optional task choice lives inside Agent & space options. Chapters, sections and subsections are optional scope choices; users must not pick paragraphs.

Actual Express/SQLite backend and React/Vite frontend. Team members use their own managed ChatGPT accounts with no account or billing fallback. Trial duplicate only; original/maintained writes and scheduling remain gated. Native equation formulas require honest supported/manual editing guidance; preservation is not scientific validation. Private assets require tested HTTPS capability transfer. Four real personal consents and real phone access must be verified separately from mocks.

User requests a complete replacement of the prior compact interface, inspired by Google One and GitHub's spacious modern start pages, with dark and light modes and an original friendly solar/wind companion. ## Product Principles
Functionality and evidence first. Show exact changes before writes. Keep the next action obvious. Protect native research content and make uncertainty visible. Preserve time for revisions and printing.
